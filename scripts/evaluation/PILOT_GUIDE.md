# Pilot үнэлгээ хийх заавар

Энэ туршилтаар детектор бүрийн **Recall** (бодит зөрчлийн хэдийг илрүүлсэн),
**Precision** (дохиоллын хэд нь зөв байсан), **F1**, **илрүүлэх хоцролт**, мөн
**хэвийн шалгалтын нэг цагт гарах худал дохиоллын тоо**-г хэмжинэ.

Гараар шошголох шаардлагагүй: оролцогч дэлгэцийн зааврыг дагаж тогтсон үйлдлүүдийг хийх
бөгөөд алхам бүрийн эхлэх цагийг сервер өөрөө бүртгэнэ (ground truth). Тайлангийн скрипт
эдгээр цагийг системийн event-үүдтэй тулгана.

## 1. Бэлтгэл (нэг удаа)

1. `backend/.env` файлд нэмнэ:
   ```
   PILOT_MODE=1
   ```
   Backend-ийг дахин асаана. **Туршилт дууссаны дараа энэ мөрийг устгана.**
2. Оролцогчдын бүртгэл үүсгэнэ (PILOT01 … PILOT10):
   ```
   python scripts/evaluation/create_pilot_users.py --count 10 --password <нууц үг>
   ```
   Нэрийг бус кодыг ашигладаг тул үр дүн нэргүй (pseudonymous) байна.
3. Хэрэгсэл: вэбкамер + микрофонтой компьютер (Chrome), гар утас, ном/дэвтэр, цаас үзэг.
   Туслах хүн байвал «хоёр дахь хүн», «ярилцах» алхмуудыг хийнэ. Байхгүй бол
   картан дээрх «алгасах» товчийг дарна; тайланд тэр алхмыг тооцохгүй.
4. Зөвшөөрөл: оролцогч бүрт туршилтын зорилго, юу хадгалагдахыг (зөрчлийн мөчийн камерын
   зураг, үйлдлийн бүртгэл; видео/дуу бичлэг хадгалагдахгүй) тайлбарлаж, амаар эсвэл
   бичгээр зөвшөөрөл авна.

## 2. Оролцогч бүрээр (~12 минут)

1. Оролцогч `PILOTxx` кодоор нэвтэрч, нөхцөлийг зөвшөөрөөд «Шалгалт эхлэх» дарна (бүтэн дэлгэц).
2. Баруун талд «Камерыг тохируулж байна» гэсэн бичиг алга болтол дэлгэц рүү хэвийн харна.
3. Дэлгэцийн доод хэсгийн картан дээрх **«Туршилт эхлүүлэх»** товчийг дарна.
4. Картан дээрх зааврыг дагана. Дэлгэц рүү харахгүй үед дохиогоор чиглүүлнэ:
   - **1 өндөр дохио** = шинэ үйлдлээ хий
   - **2 нам дохио** = хэвийн байдалдаа буц
   - **3 дохио** = туршилт дууслаа
5. Дууссаны дараа «Илгээх» товчийг дарна.

Туршилт удирдагч хажууд нь сууж, алхам бүр зөв хийгдсэн эсэхийг тэмдэглэнэ
(жишээ нь «PILOT03 — phone_lap: утсаа гаргаж амжаагүй»). Буруу хийгдсэн гүйлтийг
тайлан гаргахдаа `--sessions`-оор хасна.

**Олон янз байдал:** боломжтой бол өөр өөр өрөө, гэрэлтүүлэг, нүдний шил, зөөврийн компьютерийн
болон гадаад камер ашиглана. Энэ нь үр дүнг бодит нөхцөлд ойртуулна. Нөхцөлийг тэмдэглэж авна.

## 3. Протокол (`backend/pilot_protocol.json`)

| Төрөл | Алхмууд | Хэмжих зүйл |
|---|---|---|
| Хэвийн | normal_1 … normal_10 (нийт 5.5 мин) | Цагт ногдох худал дохиолол |
| Эерэг | look_left/right, phone, phone_lap, book, leave, second_person, talk, whisper, tab | Recall, хоцролт |
| Хүндрэлтэй сөрөг | write_paper, read_aloud, typing | Хэвийн боловч андуурагдаж болох үйлдэл |

## 4. Тайлан гаргах

```
python scripts/evaluation/pilot_report.py
python scripts/evaluation/pilot_report.py --sessions 41,42,45     # зөвхөн сонгосон гүйлтүүд
```

`scripts/evaluation/results/` дотор дараах файлууд үүснэ:
- `pilot_report.md` — дипломд оруулах хүснэгтүүд (95% итгэх интервалтай)
- `pilot_steps.csv` — гүйлт × алхам бүрийн үр дүн, хоцролт
- `pilot_matrix.csv` — алхам бүрд ямар event гарсан (confusion маягийн хүснэгт)
- `pilot_metrics.json` — бүх тоо

## 5. Үр дүнг тайлбарлах

- **Түүврийн хэмжээ:** 10 оролцогчтой бол эерэг алхам бүрт ~10 туршилт гарна. 10-аас 9 нь
  илэрвэл recall 90%, гэхдээ 95% итгэх интервал нь ~60–98%. Тиймээс тоог интервалтай нь хамт бичнэ.
- **Жүжигчилсэн үйлдэл:** бодит хуулалт илүү далд байдаг тул эндээс гарсан recall бодит нөхцөлөөс
  өндөр байх хандлагатай. Үүнийг хязгаарлалт хэсэгт заавал бичнэ.
- **Худал дохиолол / цаг** нь багшид хамгийн их нөлөөлдөг хэмжүүр: жишээ нь «хэвийн 50 минутын
  шалгалтад дунджаар 1.2 medium+high дохиолол» гэж тайлбарлана.
- **Хүндрэлтэй сөрөг** алхамд дохиолол гарсан бол («чанга уншихад яриа гэж бүртгэсэн») энэ нь
  алдаа бус бодлогын асуудал байж болно — дипломд хэлэлцүүлгийн хэсэгт ашиглана.
- Precision нь event-ийн түвшинд, recall нь алхмын түвшинд тооцогддог (event detection-д түгээмэл
  арга). Нэг алхамд хэд хэдэн event гарч болох тул precision-ий хуваарь recall-ийнхаас өөр байна.

## 6. Дууссаны дараа

- `backend/.env`-ээс `PILOT_MODE=1`-ийг устгаж backend-ийг дахин асаана.
- Pilot бүртгэлүүд DB-д үлдэнэ; шаардлагагүй бол багшийн самбараас session-уудыг архивлана.
